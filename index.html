Azeroth Survivors save editor

Point this at your save, wherever it sits. Paste a path, browse to characters.txt or a .sav, or browse to the game folder and the editor will look inside it. Close the game before you write, or it will overwrite the file when it exits.

Looking for a save.

Talent XP is the account level for a class. 23,205 XP is all 51 points. Ranks is the spent-talent list the game already stored. Leave it alone unless you know the tokens.

ClassXPPointsRanks

Worn pieces for this class. Format is slot:itemId,slot:itemId. Unlocking the collection does not equip it.

Stats

One key=value per line. kills, gold, guardians, bosses, runs, wins, caches are the ones the game writes.

Codex

One id=quality per line. Quality runs from 0 up. The button sets every listed entry to 4.

Achievements

One achievement id per line, such as zone:elwynn or class:druid. New ids get a timestamp. Existing timestamps stay.

Every line in the save. Add a line to add a record. Apply replaces the whole save in memory. Save to game writes it.
